# Emblem Studio — Lite

On-site opt-in forms, popups, ribbons and slide-ins — hand-authored HTML/CSS, with
FunnelKit Automations support. This is the **free Lite edition**: the free feature set,
plus the connector that pairs the site to an Emblem Studio (SaaS) account and embeds the
dashboard.

> **⚠ Generated build — do not edit here.**
> This repository is a **build artifact**. Every file is generated from the full plugin by
> `bin/build-lite.sh` in the private source repo (`serenichron/emblem-studio`): it copies the
> shipped plugin, strips the account-gated (Free/Paid) modules, folds in the SaaS connector, and
> flips the edition to `lite`. Edit the source there, not here — changes made directly in this
> repo are overwritten on the next build.

- **Version:** mirrors the full plugin exactly (same version, published at the same time).
- **Install:** upload the folder to `wp-content/plugins/`, or install the release `.zip`.
